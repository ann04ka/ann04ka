### [YADRO — подсчёт коробок на паллетах](https://github.com/ann04ka/Box_Counter)

Хакатон длился 2 дня. Задача: по двум фотографиям с разных ракурсов посчитать количество коробок каждого типа.

Что сделала:
- Впервые открыла Blender и собрала в нём идентичную сцену для генерации синтетических данных
- Реализовала двухголовую архитектуру с attention для смешивания признаков с двух кадров — это дало прирост точности по сравнению с обычной конкатенацией (подтвердили экспериментально)

### [SpbTechRun — агент для медицинских данных](https://github.com/ann04ka/Med-agent-F1)

Кейс от правительства СПб: LLM-агент для анализа и поиска инсайтов в медицинских данных.

Архитектуру агента можно было сделать лучше, но зато получилась хорошая аналитическая часть: анализ самых частотных назначений, выявление паттернов в данных. Плюс сделала удобный интерфейс, который понравился жюри.

### [X5 Group — LLM-тренажёр](https://github.com/ann04ka/ai-trainer)

Тренажёр софт-скиллов, где LLM симулирует рабочие ситуации в зависимости от уровня сотрудника. Методисты задавали сценарии:
- Продавец → отработка возражений клиентов
- Менеджер → конфликты в команде
- Директор → постановка задач на крупные проекты

Мы сделали адаптивную систему, которая подстраивается под роль и уровень сложности.
